# AGENTS.md

Guidance for coding agents working in this repository. [CONTRIBUTING.md](CONTRIBUTING.md) has the full contributor guide.

## Repository

- The provider is built on the Terraform Plugin Framework and lives in `internal/provider`: `provider.go` is the entry point, and each resource and data source has its own file with a matching `_test.go` file.
- The documentation in `docs/` is generated by [terraform-plugin-docs](https://github.com/hashicorp/terraform-plugin-docs) from the schema descriptions, the layouts in `templates/` and the files in `examples/`. Never edit `docs/` by hand: change the source and regenerate from the repository root with `go run github.com/hashicorp/terraform-plugin-docs/cmd/tfplugindocs generate --provider-name terraform-provider-checkly`.
- Before opening a pull request, run `go build ./...`, `go vet ./...` and `go test ./internal/...`.
